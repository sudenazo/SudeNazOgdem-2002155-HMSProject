# HMS Navigation App

A mobile navigation application built with Huawei Mobile Services (HMS).

## Features
- Location-based services via HMS Map Kit
- Secure user authentication via OAuth2 (HMS Account Kit)
- REST API integration with cloud backend
- Cloud deployment on Huawei Cloud

## Tech Stack
`Kotlin` `REST API` `OAuth2` `Huawei Cloud` `HMS SDK`

## About
Developed as part of a university project at Bahcesehir University (2022–2023).
Focused on API integration, secure authentication flows, and cloud-based backend services.
